# PDF 扫描裁边 (pdf-scan-crop)

Windows 桌面程序，用来处理**扫描版 PDF**：自动裁掉扫描脏边、全书统一裁边、旋转与校直、整理页序（排序 / 删页 / 插页）、按需 OCR，并把每一本书的手工调整自动记住。桌面快捷方式：`Apps\DIY\PDF扫描裁边.lnk`。

当前版本 **2026.10.22.2** · 界面中文 / English 可切换 · 图形界面 + 命令行双入口

## 1. 快速开始

1. 双击 `PDF裁边.exe`（或桌面快捷方式），也可以把 PDF 直接拖到 exe / 快捷方式上打开。
2. 点「**分析预览**」。分析完成后蓝色框就是自动裁切范围。
3. 需要的话手调（拖蓝框、改坐标、旋转、统一裁边、页面整理）。
4. 点「**生成 PDF**」。默认输出到原书旁边的 `原名_裁边.pdf`，**不会覆盖原书**。

只想统一裁掉一圈边、不想等分析时：点「统一裁边（全书同尺寸）…」填好数值，直接点里面的「**按此生成 PDF**」。

## 2. 裁切

### 2.1 自动去脏边（默认）

只切最外侧真正发黑的扫描边、装订阴影和脏污，**空白纸边尽量保留**——正文、脚注、题注、表线、水墨和正常页边都不会被切掉。

- 页边暗线、阴影裁得过深时会自动收回，只裁到暗线或阴影外约页宽 **2%** 处（这一步只会少裁，不会多裁）。
- 封面、盖章页等整页偏色的页面不做这一步。
- 稀疏页有「最少保留比例」兜底（默认相对原始扫描保留 **90%** 宽高，高级选项可调），避免被裁得过小。
- 书脊页会按整条书脊外缘裁（左侧暗面、印面、右侧折边都保留），只去掉白边和外侧相邻封面。
- 对页扫描会按中间白槽切开；但一侧只是表栏或水墨时不会误切。

### 2.2 贴着文字紧裁（可选）

勾选「**贴着文字继续往里裁（会多切掉空白页边）**」后，按文字外框往里收，把多余空白页边也切掉。默认不勾。

### 2.3 手工裁切框

- **拖蓝框**：拖动边角/边线调整；拖动时只改预览，松开鼠标才写入并记入该页的手工设置。
- **坐标框**：直接改「左 / 上 / 右 / 下」数值（像素，基于该页裁切前的图像尺寸）。
- **「本页不裁切」**：当前页改成整页保留（输出整页）。
- **「全部不裁切（每页整页）」**：一次改完全书，生成时不再裁边。
- **「恢复本页自动裁切」**：丢掉该页的手工框，重新按自动结果算。
- **「全屏裁切」（F11）**：大屏看清再改；滚轮缩放、「放大 / 缩小」按钮、按住空白处拖动平移；全屏底部同样有旋转滑条和左右转 90°；Esc 退出。
- **「隐藏设置」**或把灰杠拖到底，也能把裁切区拉高。

### 2.4 统一裁边（全书同尺寸）

点「**统一裁边（全书同尺寸）…**」，左 / 上 / 右 / 下分别填，单位可切 **厘米 / 毫米 / 英寸**。

- 尺寸从**每页原始页边**量起，按输出 PDF 的实际尺寸换算，与扫描分辨率无关。
- 幂等：重复设同一数值结果不变；自动裁边已经裁得更内侧的地方保留更内侧的线（只会少裁）。
- 应用后蓝框立即更新，可翻页检查；把数值改回 **0** 再确定即恢复统一裁边前的裁切框。
- **免分析快速模式**：还没点过「分析预览」时，对话框里可直接点「按此生成 PDF」，跳过分析直接生成。

## 3. 旋转与校直

- **自动校直**（默认开启）：分析时把歪的书脊、轻微倾斜的页面转正；书脊页按内缘竖直边搜索小角度。
- **滑条 / 数字框**：范围 **-180°～180°**，**正值是逆时针**。改数字只预览，点「应用旋转」或松开滑条后才重算。
- **单页 90°**：旋转滑条旁边的「左转 90° / 右转 90°」，按一下转一页；全屏模式里同样有；可以连按累计（转 180° 也行）。
- **全书旋转**：左栏「全书左转 90° / 全书右转 90°」把整本书一次转正。已分析的页面会按新方向自动重算裁切框；**手工拖过的裁切框不保留**（旋转后坐标不再适用），统一裁边设置和每页旋转角度会累计保留。

## 4. 页面整理（排序 / 删页 / 插页）

点左栏「**页面整理（排序 / 删页 / 插页）…**」打开整理窗口，**不必先「分析预览」**。

### 4.1 排序

- 缩略图网格，一行多页，直接**拖动缩略图**换位置；落点在目标格子左半边 = 放到它之前，右半边 = 放到它之后，拖到空白处 = 移到末尾。
- **Ctrl / Shift 多选**后可以整块拖；块内相对顺序不变。
- 「上移 ↑ / 下移 ↓」对多选同样整块生效。
- 「**移到第 N 页**」：填页码点「移动」，几百页的书一步到位。
- 「**全屏**」（按钮或 F11）放大操作，Esc 在全屏时退出全屏。
- 每次插入 / 删除 / 恢复 / 移动 / 拖动后，条目上的**页码立即重排**。

### 4.2 删除与恢复

- 「**删除所选**」：源页面移出输出，可在下方「已删除的页」里用「**恢复所选**」放回（放到末尾）。
- 删除**插入页**则是整个移除（记录与图片一并清除）。
- 只有明确点「删除所选」才会移除页面；拖动、排序、整理窗口的其它操作都不会误删。
- 「**恢复原顺序**」：把当前所有页面按源页号重排（含已删除的页）。

### 4.3 插入页面

整理窗口里可插入四类内容：

| 类型 | 说明 |
|---|---|
| **插入 PDF 页** | 选好源 PDF 后弹出**该 PDF 的页面缩略图**，勾选要插入的页（全选 / 全不选 / 反选）；顶部也能直接输入页码（如 `3,7,10-12`）后点「应用」。 |
| **插入图片** | 可多选；会询问是否「**自动优化**」（提亮纸面、加深字迹，像一般扫描软件）。 |
| **插入空白页** | 尺寸随当前书的第一页。 |
| **复制所选页** | 复制当前页（含裁切、旋转），副本可独立调整。 |

插入完成后，结果表会自动选中并滚动到新插入的页。

> **页码规则**：界面上显示的页码一律是「**整理后的页码**」，插入页与原有页**完全等价**——插在第 2 页后的就是「第 3 页」，后面的页顺延。内部用于持久化的稳定键不会在任何界面出现。

### 4.4 不开整理窗口也能操作

- 主窗口下方**结果表**里可以直接拖动行排序（多选后一起拖）。
- 表格右键菜单：上移 / 下移 / 删除 / 恢复 / 复制 / 插入（PDF / 图片 / 空白）/ 页面整理。
- 导航栏有「**删页**」按钮。

## 5. 只导出部分页面

两种方式，都是用「整理后的页码」，**插入页同样可以选**：

1. 在「**只处理这些页（按整理后的页码）**」里填页码，如 `3,7,10-12`。
2. 点它旁边的「**按缩略图选页…**」，在缩略图里勾选（全选 / 全不选 / 反选），确定后自动填进上面的输入框。

- 分析和生成都只处理选中的页；只选插入页时会完全跳过源页面分析。
- 格式错误、页码超范围会在状态栏提示；把页面全删光或选空时会提示，不会生成空 PDF。

## 6. 输出与版式

- 输出 PDF 每页高度统一映射到 **A4 高度（841.89 pt）**，宽度按裁切后的比例，所以整本书版面一致、便于阅读和打印。
- 书签沿用原书目录，删除 / 插入页面后按新页码重排；页码标签、书名、作者一并带过去。
- 「生成 PDF」不会修改源文件；输出默认 `原名_裁边.pdf`，可改路径。
- 「打开输出」「打开文件夹」方便直接查看结果。

## 7. OCR

- 依赖 **Tesseract**：`C:\Program Files\Tesseract-OCR\tesseract.exe`；语言字库随程序放在 `tessdata\`（默认使用，无需额外安装）。
- **默认不勾选「生成时 OCR」**——先裁边会快很多。扫描件没有文字层，需要复制文字时再勾选，或事后点「OCR 全书」。
- 「**OCR 本页**」先试一页。
- 「**OCR 全书**」按当前裁切一键识别全书并写入可复制文字层：先抽约 6 页样本判断全书是繁中、简中还是日文（混排的书会同时保留几种），其余页只跑选中的语言，并带英文；若源 PDF 旁边有 `书名_LaTeX.pdf`，会自动拿来当词表校正。
- 写入的字体做**子集化**，不会因此让 PDF 膨胀十几 MB。
- 需要纯文本时勾选「另外写出同名 txt」；也可把**已生成的裁边 PDF** 填进输出路径后直接点「OCR 全书」补文字层，不必重新裁切。

## 8. 记忆、缓存与日志

### 8.1 自动记住每本书的手工调整

以下内容会按书保存，重开同一本书时自动恢复：手工裁切框、旋转角度、统一裁边前的原框、页面顺序、删页、插入页（含插入图片与来源信息）。

- 「高级选项 → **清除本书手工调整**」：把以上全部作废（含插入页图片），不影响源文件。
- 编辑记录：`%LOCALAPPDATA%\PDF裁边\edits\<书名-指纹>.json`
- 插入页图片：`%LOCALAPPDATA%\PDF裁边\imports\<书名-指纹>\`（与缓存分开，「清理缓存」不会删）

### 8.2 缓存

- 页面图缓存：`%LOCALAPPDATA%\PDF裁边\cache\<书名-指纹>\`，不再堆在 PDF 旁边。
- 同一本书再次处理时，勾选「**复用已抽出的页面图**」会快很多。
- 缓存与 PDF 不匹配（换了文件）时整批旧图自动作废。
- 「高级选项 → **清理缓存**」一次删掉所有书的页面图；只删程序自己生成的 `page-NNN.jpg` 之类，目录里的其它文件一律不动。

### 8.3 运行日志

- 路径：`%LOCALAPPDATA%\PDF裁边\运行日志.log`（超过 2 MB 自动轮换为 `.old`）
- 记录：打开的书、分析与生成进度、插入 / 移动 / 删除 / 恢复页面、统一裁边、旋转、OCR、自检，以及**任何异常的完整堆栈**（包括未被界面接住的异常）。
- 遇到问题先看这个文件的末尾几行。

### 8.4 内置自检

```powershell
PDF裁边.exe --self-test "$env:TEMP\selftest.txt"
```

离屏运行，检查 Qt 窗口、PyMuPDF、裁切引擎、OCR、字体子集化、统一裁边快速模式、旋转、插入页、页面整理、缩略图、过滤器、导航等，全部 PASS 才算正常。

## 10. 命令行 fix_pdf_edges.py

引擎可单独使用（`source\fix_pdf_edges.py`），适合批处理：

```powershell
python fix_pdf_edges.py 书.pdf                                  # 只去脏边
python fix_pdf_edges.py 书.pdf --crop-mode content              # 贴文字紧裁
python fix_pdf_edges.py 书.pdf --uniform-crop 0,0,0,2           # 直接按统一边距生成（厘米）
python fix_pdf_edges.py 书.pdf --pages 5-20 --reuse-images      # 只处理部分页并复用缓存
python fix_pdf_edges.py 书.pdf --ocr --ocr-lang chi_sim+eng      # 带 OCR
python fix_pdf_edges.py --ocr-existing 已裁边.pdf                # 给已有 PDF 补文字层
```

| 参数 | 说明 |
|---|---|
| `input` / `-o, --output` | 源 PDF / 输出 PDF |
| `--work-dir` | 页面图缓存目录 |
| `--reuse-images` | 仅在缓存与当前 PDF 匹配时复用页面图 |
| `--pages` | 只处理部分页，如 `1,2,10-12` |
| `--crop-mode {edges,content}` | edges=只去脏边（默认）；content=贴文字紧裁 |
| `--uniform-crop L,T,R,B` | 跳过内容分析，按厘米统一裁边，如 `0,0,0,2` 或 `2` |
| `--page-crop PAGE:L,T,R,B` | 单页手工裁切（像素），可重复 |
| `--page-rotate PAGE:DEG` | 单页旋转（Pillow 角度，正值逆时针），可重复 |
| `--auto-rotate / --no-auto-rotate` | 自动校直（默认开） |
| `--min-page-ratio` 等 | 稀疏页最少保留比例（内容模式） |
| `--min-full-page-ratio` 等 | 相对原始扫描的最少保留比例（默认 0.90） |
| `--report` | 写出 CSV 裁切报告 |
| `--inspect-pages / --inspect-dir / --inspect-dpi` | 渲染检查图 |
| `--jobs` | 并行分析线程数（默认 14，0=自动，1=串行） |
| `--render-dpi` | 没有整页 JPEG 时的栅格化 DPI（默认 600） |
| `--backend {auto,pymupdf,poppler}` | PDF 图像后端（默认 PyMuPDF） |
| `--analyze-only` | 只分析、写报告，不生成 PDF |
| `--ocr / --no-ocr`、`--ocr-txt`、`--ocr-lang` | OCR 选项 |
| `--ocr-existing PDF` | 给已生成的裁边 PDF 补文字层 |

> 输出文件与源文件相同路径时程序会拒绝，避免覆盖原始扫描。

## 12. 构建、测试与发布

### 目录结构

    PDF裁边.exe          打包好的程序
    _internal\           PyInstaller 运行时（Qt、Python 库等）
    tessdata\            Tesseract 语言字库
    使用说明.txt          面向用户的简明说明
    source\              本构建对应的源码快照（含构建脚本）
    README.md            本文件

源码工作副本另存于 `Desktop\文件\文献处理\`（`pdf_crop_app.py` 界面、`fix_pdf_edges.py` 引擎）。

### 依赖

- **Python 3.14**（PyInstaller 打包）
- **PySide6**（界面）、**PyMuPDF**（PDF 渲染/抽取）、**Pillow**、**NumPy**
- **Tesseract OCR**（可选，运行时从 `C:\Program Files\Tesseract-OCR\` 调用；字库随程序分发）

### 打包

```powershell
cd source
.\build_pdf_crop_exe.ps1              # 构建并部署
.\build_pdf_crop_exe.ps1 -NoDeploy    # 只构建到 %TEMP%\pdf_crop_dist
```

脚本按 `PDF裁边.spec` 用 PyInstaller 构建到 `%TEMP%\pdf_crop_dist`，补上 `tessdata\`、使用说明和 `source\`，再镜像到 `C:\Users\<用户>\PDF裁边\`，同时保留 `.git`、`.claude`、`README.md`、`.gitignore`。版本号在 `source\pdf_crop_version.txt`（文件属性里可见）。

### 发布注意

- PyInstaller 产物（`PDF裁边.exe`、`_internal\`）被 git 跟踪，重新构建后要一起提交。
- 更新程序时两个目录都要同步：`C:\Users\<用户>\PDF裁边\` 与 `%LOCALAPPDATA%\Programs\PDF裁边\`（AppData 副本不带 `source\`）。
- 程序正在运行时 exe 被占用，无法直接覆盖；先关闭程序，或先把旧 exe 改名再拷入新 exe。

### 自检

    PDF裁边.exe --self-test 报告.txt

## 13. 常见问题

**问：为什么插入页显示的页码是“第 N 页”？**
答：界面上一律使用整理后的页码，插入页和原有页完全等价；内部稳定键只在存档里使用，不会显示。

**问：移动页面后页面不见了？**
答：已修复的两个原因（拖放时 Qt 自行删除被拖行、整理窗口漏项导致记录被清）都不再存在；现在插入页只有明确「删除所选」才会移除。若仍遇到，请查看 `运行日志.log` 末尾。

**问：插入的来源 PDF 找不到了 / 打开时提示来源不可用？**
答：程序会保留一个占位页（表格备注 `import+missing`），你可以删除它，或把来源文件放回原处后再调整。

**问：页码超出范围 / 插入失败？**
答：从 PDF 插入时会先核对源文件页数；越界页码只跳过该页并提示，同批次的其它页仍会插入。

**问：裁得太少或太多？**
答：默认「只去脏边」偏保守。想更紧就勾「贴着文字继续往里裁」；只想统一裁掉一圈就用手工「统一裁边」；个别页可在整理窗口或主界面手工拖框覆盖。

**问：生成很慢？**
答：先不勾「生成时 OCR」；线程默认 14（本机 14 线程，调高反而更慢）；同一本书再次处理时勾「复用已抽出的页面图」；只处理需要的页。

**问：OCR 识别不出中文？**
答：确认 `tessdata\` 完整、Tesseract 已安装；程序会先抽样判断文种，混排书会保留多种语言。也可先用「OCR 本页」试效果。

**问：原书会被改动吗？**
答：不会。程序只读源 PDF，输出另存为 `原名_裁边.pdf`（或你指定的路径）；输出与源路径相同时会拒绝执行。

**问：更新后还是旧界面？**
答：关掉所有窗口再重开；程序运行时 exe 无法被覆盖。
