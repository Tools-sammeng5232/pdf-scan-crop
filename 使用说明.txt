PDF 扫描裁边

双击「PDF裁边.exe」即可使用，不必再打开命令行。也可以把 PDF 拖到 exe 或快捷方式上直接打开。

用法
1. 点「浏览」选择扫描版 PDF，或把 PDF 拖进窗口。
2. 程序会自动填好输出文件名（原名_裁边.pdf），不会覆盖原书。
3. 先点「分析预览」。分析完成后，蓝色框是自动裁切范围。默认只去掉脏边，空白页边会尽量留下。若整书都不想裁，点「全部不裁切（每页整页）」即可。
4. 统一裁边：想让全书裁掉同一尺寸（例如每页下方都裁 2 厘米），点「统一裁边（全书同尺寸）」，左 / 上 / 右 / 下分开填，单位可切换厘米 / 毫米 / 英寸。尺寸从每页原始页边量起，按输出 PDF 的实际尺寸换算，与扫描分辨率无关；重复设置同一数值结果不变，自动裁边裁得更多的地方保持更内侧的线。应用后蓝框立即更新，可翻页检查；尚未分析时也可以直接点「按此生成 PDF」免分析快速生成。把数值改回 0 再确定，即可恢复统一裁边前的裁切框。
5. 用左右方向键或「上一页 / 下一页」翻页；翻页按整理后的输出顺序走，插入的页面也能翻到。手工裁切区可用滚轮或「放大 / 缩小」看清页面，按住空白处拖动平移。点「全屏裁切」（或 F11）可全屏改裁切，底部仍有旋转滑条和左右转 90°，不必退出全屏；Esc 退出。点「隐藏设置」或把灰杠拖到底也能拉高裁切区。可拖动蓝框，或改左/上/右/下数字；拖蓝框时只改预览，松开后再写入。「本页不裁切」把当前页改成整页保留；「全部不裁切（每页整页）」一次改完全书，生成时不再裁边。窗口右上角可切换中文 / English，选择会记住。
6. 单页 90° 旋转：旋转滑条旁边有「左转 90° / 右转 90°」按钮，按一下转一页；全屏模式里同样有。可以连按累计（转 180° 也行）。
7. 全书旋转：左栏「全书左转 90° / 全书右转 90°」把整本书一次转正。已分析的页面会按新方向自动重算裁切框；手工拖过的裁切框不保留（旋转后坐标不再适用），统一裁边设置和每页旋转角度会累计保留。
8. 默认勾选「自动校直歪斜页面」：分析时会把歪的书脊、轻微倾斜的页面转正。书脊页会按整条书脊外缘裁（左侧暗面、印面、右侧折边都保留），只去掉白边和外侧相邻封面。
9. 也可取消自动校直，用下方滑条手调，范围 -180° 到 180°。正值是逆时针。改数字只预览，点「应用旋转」或松开滑条后才重算。
10. 若确实想贴着文字多裁，再勾选「贴着文字继续往里裁」。
11. 页面整理（排序 / 删页 / 插页）：移动页面后，裁切区会跟着你正在看的那一页走，不会跳到别的页（拖动、排序都会记入运行日志），下方结果表也会同步选中当前页；插入页只有明确点「删除所选」才会消失，拖动、排序不会误删；点「页面整理」打开整理窗口，不必先「分析预览」。缩略图一行多页，Ctrl + 滚轮（或 Ctrl + / -）缩放缩略图大小；直接拖动缩略图即可换位置（按住 Ctrl / Shift 多选后可整块拖）；几百页的书用「移到第 N 页」一步跳转，也可用「全屏」（或 F11）放大操作；条目上的页码就是整理后的页码，插入页和原有页完全等价：插在第 2 页后的就是「第 3 页」，后面的页顺延。未分析的页面在生成时会自动补算。「删除所选」把源页面移出输出（可用「恢复所选」放回末尾），删除插入页则是整个移除；插入其他 PDF 时直接弹出来源 PDF 的缩略图，点选要插入的页即可（也可在页码框输入后点「应用」；个别页码无效不会丢掉其他页）；插入完成后下方结果表会自动选中并滚动到新页。可插入其他 PDF 的指定页码、插入图片（可选自动优化：提亮纸面、加深字迹，像一般扫描软件）、插入空白页、复制某一页。不开整理窗口也能直接操作：下方结果表里拖动行排序（多选后一起拖），右键菜单有上移 / 下移 / 删除 / 恢复 / 复制 / 插入，导航栏有「删页」按钮。顺序只影响生成的 PDF，不会改动源文件。
12. 检查无误后点「生成 PDF」。生成前可只导出部分页面：点页码框旁的「按缩略图选页…」，在缩略图里勾选要导出的页（可全选 / 全不选 / 反选），也可以直接在「只处理这些页」里填页码（如 3,7,10-12）；两种方式填的都是整理后的页码，插入页同样能选；填错格式或超出页数会在状态栏提示，全删光或选空时不会生成空 PDF。默认不勾选「生成时 OCR」，先裁边会快很多。扫描件没有文字层，需要复制文字时再勾选 OCR，或事后点「OCR 全书」。OCR 会先抽几页样本，判断全书是繁中、简中还是日文（混排的书会同时保留几种），其余页只跑选中的语言，并带英文。若源 PDF 旁边有「书名_LaTeX.pdf」，会自动拿来当词表校正。
13. 「OCR 本页」试一页；「OCR 全书」按当前裁切一键识别全书并写入可复制文字层。若已经生成过裁边 PDF，可把该文件填进输出路径后直接点「OCR 全书」，不必重新裁切。同名 txt 默认不写，需要时勾选「另外写出同名 txt」。
14. 手工拖过的裁切框、旋转角度、统一裁边前的原框、页面顺序、删页和插入页都会自动保存，下次打开同一本书时自动恢复；不想要了，在「高级选项」点「清除本书手工调整」。
15. 程序不生成 CSV 报告。原书的目录书签、页码标签和书名、作者会带到裁边 PDF 里；插入页和删页后的顺序也会正确映射书签。

说明
- 默认策略是去脏边、少切除，优先保住正文、脚注、题注、表线、水墨和正常空白边。
- 页边暗线、阴影裁得过深时会自动收回，只裁到暗线或阴影外约页宽 2% 处，多留一点纸面；这一步只会少裁，不会多裁。封面、盖章页等整页偏色的页面不做这一步。
- 「贴着文字继续往里裁」才会按文字外框往里收，稀疏页可用高级选项里的最少保留比例兜底。
- 运行日志在 %LOCALAPPDATA%\PDF裁边\运行日志.log（超过 2 MB 自动改名为 .old），插入失败、页面打不开等错误会连同堆栈一起记下来，方便排查。
- 插入页的记录不会被悄悄丢掉：图片或来源暂时不可用时会保留成一个占位页（表格里注 import+missing），可以在整理窗口里删除它，或之后再补。
- 页面缓存图放在 %LOCALAPPDATA%\PDF裁边\cache\，不再堆在 PDF 旁边。同一本书再次处理时，勾选「复用已抽出的页面图」会快很多；「高级选项」里的「清理缓存」可一次删掉所有书的缓存图，手工调整记录保留。
- 插入页自己的图片放在 %LOCALAPPDATA%\PDF裁边\imports\（按书分文件夹），与缓存分开，「清理缓存」不会删掉它们；「清除本书手工调整」会把顺序、删页、插入页一并清除。
- 重建缓存时只删除程序自己生成的页面图（page-000.jpg 之类），缓存目录里的其他文件一律不动，所以缓存目录误填成普通文件夹也不会被清空。
- 默认并行线程 14、渲染 DPI 600；改 DPI 后会重新抽图。界面设置（语言、线程、勾选项、窗口大小）保存在 %APPDATA%\PDF裁边\PDF裁边.ini。
- 带 OCR 的 PDF 只嵌入用到的字形，不会因为字体多出十几 MB。
- 命令行程序 fix_pdf_edges.py 仍然保留（程序旁 source 文件夹里有一份构建时的源码）；默认 --crop-mode edges，旧行为用 --crop-mode content。新增 --uniform-crop L,T,R,B（厘米，从原始页边量起）可跳过分析直接按统一边距生成，例如 --uniform-crop 0,0,0,2。
